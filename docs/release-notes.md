# CabinGraphicsProfiles 0.1.0

> 🛟 **Need help or found a bug?** Get support at [support.doodesch.de/graphicsprofiles](https://support.doodesch.de/graphicsprofiles).

Choose **Balanced** or **Performance** for global illumination, shadows, reflections and effects. **Restore previous** returns these groups to their original values. Other graphics options stay unchanged; no profile is applied on startup.

Requires [UE4SS 3.0.1 or later](https://www.nexusmods.com/thecabingame/mods/4). Use [Mod Settings](https://www.nexusmods.com/thecabingame/mods/6) for the profile menu.
